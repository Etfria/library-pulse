What stands out?

01_monthly_loans.xlsx

Columns: Loan Year, Loan Month Key, and an unnamed loan-count column. Powers the Loans KPI, the circulation trend chart, and the peak/lowest month figures. The export covers a rolling 12-month reporting window, {{ periodSpan }}, delivered as {{ monthRowCount }} monthly rows because both endpoint months are partial. {{ partialNote }}.

02_loans_by_patron_group.xlsx

Columns: Library Name (Active), User Group, Loans (In House + Not In House), Year. Powers “Who is borrowing?”. Years {{ yearRange }} appear in the export, so its totals cover a much longer span than the circulation chart and are never combined with it. Blank Library Name or User Group values are labelled as not recorded.

04_inventory_by_location.xlsx

Columns: Location Name, Loans, Loans/Items, Num of Items (In Repository), Library Name (Active). Powers “Recorded collection utilization”. Its Loans column is a recorded, cumulative Alma measure with no stated period; it is not the rolling circulation window and is not comparable to report 01. Loans/Items is blank where a location holds no items — those rows are excluded from the ranking rather than treated as zero.

Loans - Items ratio per Classification.xlsx

Columns: Loans, Loans/Items, Num of Items (In Repository), Group1 (Holdings). Powers “Subject utilization”. The export holds {{ clsGroupCount }} classification groups totalling {{ clsItemsTotal }} items and {{ clsLoansTotal }} recorded loans, which matches reports 04 and 05 on items. Its Loans column is the same recorded, cumulative Alma measure as report 04 — not the rolling 12-month window — and is never combined with it. The report carries no Library field, so the section is institution-wide and deliberately does not respond to the library filters; ownership of a classification is not inferred. The classification group “Unknown” ({{ unknownShare }}) is excluded from the ranking by default and retained in the data.

05_items_added.xlsx

Columns: Num of Items (In Repository), Material Type, Lifecycle, Library Name (Active). Used as current collection composition by material type, not as growth over time — the export carries no date dimension. Only Lifecycle “Active” rows are charted; Deleted and blank-lifecycle rows carry item counts of 0 in this export. Its Active total matches report 04’s item total exactly ({{ kpiItems }}), which is the cross-check behind the items KPI.
